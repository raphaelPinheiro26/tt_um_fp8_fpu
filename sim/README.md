# sim/ — legacy Verilog testbenches (reference only)

The original stand-alone Verilog testbenches for the FP8 FPU, kept for reference
and quick local debugging. **Not** part of the Tiny Tapeout flow (the taped-out
RTL is in `../src`, the cocotb suite in `../test`, and Python ports in
`cocotb/`). `tb_fp8_golden.v` self-checks a replay of `../Golden_model/vectors.hex`.

**Full documentation — the testbench list and how to run them — is in the wiki:**
[Simulation & Tests](../docs/wiki/Simulation-and-Tests.md#legacy-verilog-testbenches--sim).
